# Stock Inventra

**Product:** Inventory & Sales Management System

Stock Inventra is a modern, premium inventory management system designed for small and medium-sized businesses. It provides powerful tools for tracking stock, managing sales, and analyzing business performance.

## Phase
Currently in **Phase 01: Architecture Preparation**.

The monorepo structure has been established and the project is ready for the implementation of the design system and core UI components.

## Development Workflow

### Prerequisites
- Node.js (v18+)
- Yarn
- PostgreSQL

### Getting Started
1. Clone the repository
2. Run `yarn install`
3. Copy `.env.example` to `.env` and fill in your database credentials
4. Run `yarn dev` to start both frontend and backend development servers in parallel.

For more details, see [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
